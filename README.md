# Apps Móviles II

Repositorio de trabajos de Apps Móviles II. Incluye los proyectos de Parcial I
y Parcial II; el PDF de instrucciones se mantiene fuera del control de
versiones.

## Proyectos

- [Parcial I](Parcial%20I/AppI/app_todo_mundo/README.md): aplicación base de
  Flutter.
- [Parcial II](ParcialII/app_contador/README.md): contador con incremento,
  decremento, reinicio y pruebas de widgets.

Para ejecutar cualquiera de las aplicaciones, entra a su carpeta y ejecuta:

```bash
flutter pub get
flutter run
```
